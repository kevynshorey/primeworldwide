# Prime Worldwide Properties – Barbados Aggregator

A Next.js + TypeScript application that scrapes multiple Barbados real estate websites **weekly**, stores listings in a Prisma/MySQL database, and displays them in a professional, responsive UI. Seamless deployment on Vercel with a scheduled weekly cron for data scraping.

## Features

- **Weekly Scraping (Cron)**: Automatically scrape multiple Barbados property sites every Sunday at 03:00 UTC and upsert into the database.
- **Paginated Listings**: Browse all properties with pagination (newest first).
- **Advanced Filtering**: Filter by parish, price range, bedrooms, bathrooms.
- **Property Detail Pages**: Full details, image carousel, and “Contact Agent” form.
- **Contact Forms**:  
  - Property-specific inquiries → emailed to agent & stored in DB.  
  - General inquiries → emailed to site admin & stored in DB.
- **Responsive Design**: Mobile-first styling with Tailwind CSS.
- **Vercel-Ready**: Zero-configuration build/deploy. Weekly cron job configured in `vercel.json`.

---

## Tech Stack

- **Framework**: Next.js 13 (TypeScript)  
- **Styling**: Tailwind CSS  
- **Database**: MySQL (e.g., PlanetScale, Supabase)  
- **ORM**: Prisma  
- **Scraping**: Axios + Cheerio (executed via `ts-node`)  
- **Email**: Nodemailer (SMTP)  
- **Cron**: Vercel Scheduled Functions (configured in `vercel.json`)

## Getting Started (Local Development)

### Prerequisites

1. **Node.js** v18 LTS (or newer).  
2. **npm** (bundled with Node.js).  
3. **MySQL-compatible database** (e.g., PlanetScale, Supabase, or local MySQL).  
4. **Git** (for cloning the repo).

### Installation

1. Clone the repo (or copy these files into a new folder):

   ```bash
   git clone https://github.com/<your-username>/my-barbados-aggregator.git
   cd my-barbados-aggregator
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

### Environment Variables

1. Duplicate `.env.example` and rename to `.env.local`:

   ```bash
   cp .env.example .env.local
   ```

2. Open `.env.local` and fill in your real values:

   ```env
   DATABASE_URL="mysql://root:password@localhost:3306/prime_db"
   EMAIL_HOST="smtp.example.com"
   EMAIL_PORT="587"
   EMAIL_USER="user@example.com"
   EMAIL_PASS="supersecret"
   EMAIL_FROM="no-reply@primeworldwideproperties.com"

   SCRAPE_URLS="
   https://cariblist.com/,
   https://terracaribbean.com/,
   https://www.realtor.com/realestateandhomes-search/Barbados_Barbados,
   https://realtorslimited.com/,
   https://altmanbarbados.com/,
   https://barbados-sothebysrealty.com/,
   https://www.chestertonbarbados.com/,
   https://www.beavabarbados.com/
   "
   ```

   - **DATABASE_URL**: Your MySQL connection string (Planetscale/Supabase or local).  
   - **EMAIL_HOST**, **EMAIL_PORT**, **EMAIL_USER**, **EMAIL_PASS**, **EMAIL_FROM**: SMTP credentials.  
   - **SCRAPE_URLS**: Comma-separated list of websites to scrape weekly.

### Database Setup & Migrations

1. Generate the Prisma client:

   ```bash
   npx prisma generate
   ```

2. Run migrations to create tables:

   ```bash
   npx prisma migrate dev --name init
   ```

   This will:
   - Create the `Property` and `Inquiry` tables in your database.
   - Populate a new folder under `prisma/migrations/`.

### Run Locally

- Start the development server:

  ```bash
  npm run dev
  ```

  - Visit [http://localhost:3000](http://localhost:3000) to view the site.
  - Key API routes:
    - `GET /api/properties` → paginated, filtered listings.
    - `GET /api/properties/[id]` → single property details.
    - `POST /api/contact` → submit inquiries.
    - `GET /api/scrape` → manually trigger the scraper.

### Run the Scraper Manually

- To run the weekly scraper on demand:

  ```bash
  npm run scrape
  ```

  - Uses `ts-node` to execute `scripts/scrapeListings.ts`.
  - Fetches each URL in `SCRAPE_URLS`, normalizes data, upserts into your database, and logs a summary.

## Deployment to Vercel

### Step 1: Push to GitHub

1. Create a new GitHub repository (e.g., `primeworldwide-aggregator`).  
2. Push all files:

   ```bash
   git remote add origin https://github.com/<your-username>/primeworldwide-aggregator.git
   git branch -M main
   git push -u origin main
   ```

### Step 2: Import Project in Vercel

1. Log in to [Vercel](https://vercel.com/) and click “New Project.”  
2. Choose “Import from Git” and select your `primeworldwide-aggregator` repo.  
3. Vercel will auto-detect Next.js—click “Deploy.”

### Step 3: Configure Environment Variables in Vercel

1. In your Vercel Dashboard, go to **Settings → Environment Variables** for your project.  
2. Add each variable exactly as in `.env.example` (omit quotes):
   - `DATABASE_URL`
   - `EMAIL_HOST`
   - `EMAIL_PORT`
   - `EMAIL_USER`
   - `EMAIL_PASS`
   - `EMAIL_FROM`
   - `SCRAPE_URLS`

> **Tip:** For PlanetScale or Supabase, copy their generated connection string.  
> Make sure the names match exactly.

### Step 4: Verify Weekly Cron Scraping

1. The `vercel.json` includes:
   ```json
   "functions": {
     "api/scrape.ts": {
       "runtime": "nodejs18.x",
       "schedule": "0 3 * * 0"
     }
   }
   ```
   - This schedules `GET /api/scrape` every Sunday at 03:00 UTC.  
2. After the first deployment, navigate to **Functions → Scheduled Invokes** to confirm that `/api/scrape` is scheduled.  
3. Check the **Logs** tab after Sunday 03:00 UTC to see scraper output.

## API Endpoints

1. **GET `/api/properties`**  
   - Query Params:
     - `page` (number, default: 1)  
     - `limit` (number, default: 10)  
     - `parish` (string)  
     - `minPrice` (number)  
     - `maxPrice` (number)  
     - `bedrooms` (number)  
     - `bathrooms` (number)  
   - Response:  
     ```json
     {
       "data": [ /* array of Property objects */ ],
       "pagination": {
         "total": 123,
         "page": 1,
         "limit": 10,
         "totalPages": 13
       }
     }
     ```

2. **GET `/api/properties/[id]`**  
   - Response:  
     ```json
     {
       "data": { /* single Property object */ }
     }
     ```

3. **POST `/api/contact`**  
   - Body:
     ```json
     {
       "propertyId": 42,          // or null for general inquiry
       "name": "John Doe",
       "email": "john@example.com",
       "message": "I’m interested in this property..."
     }
     ```
   - Functionality:
     - Saves inquiry to `Inquiry` table (with `propertyId` = 0 if null).  
     - If `propertyId` is provided and the property has `agentEmail`, emails the agent.  
     - If `propertyId` is null or agentEmail is missing, emails site admin (`EMAIL_FROM`).  
   - Response:
     ```json
     { "success": true }
     ```

4. **GET `/api/scrape`**  
   - No parameters.  
   - Invokes the scraper (`scripts/scrapeListings.ts`) via `ts-node`.  
   - Returns:
     ```json
     {
       "success": true,
       "output": "...console logs from scraper..."
     }
     ```
